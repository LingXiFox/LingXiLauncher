## 签名与分发

| 编号 | 平台 | 现象 | 影响 | 绕过 / 说明 | 状态 |
| --- | --- | --- | --- | --- | --- |
| KI-01 | macOS | 安装包只做了 ad-hoc 签名，未做 Apple Developer ID 签名与公证 | 首次打开会被 Gatekeeper 拦截 | 右键「打开」，或系统设置 → 隐私与安全性 → 仍要打开；详见 INSTALLATION.md | 已知，RC 可接受 |
| KI-02 | Windows | 安装包未做 Authenticode 代码签名 | SmartScreen 显示「未知发布者」 | 点击「更多信息 → 仍要运行」 | 已知，RC 可接受 |
| KI-03 | Linux | AppImage 未做 GPG 签名 | 无自动校验 | 用发布页的 SHA256 校验 | 已知，RC 可接受 |

以上三项是 RC 阶段的既定状态：当前仓库没有配置 Apple / Windows 签名证书，因此**不能**声称安装包已通过 Apple 公证或 Windows 正式代码签名。
