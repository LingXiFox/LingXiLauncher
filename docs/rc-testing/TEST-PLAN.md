# v0.10.0-rc.1 测试计划

- 版本：0.10.0-rc.1（tag `v0.10.0-rc.1`）
- 目标：验证 Rust 重写版在 macOS / Windows / Linux 上的安装、登录、启动与数据迁移，为正式版收集反馈
- 主验收平台：macOS 14+（Apple Silicon）；Windows 11 与 Ubuntu 24.04 由 RC 测试者实机验证
- 产物：GitHub Pre-release 页面上的 DMG、`.app.zip`、NSIS `setup.exe`、MSI、AppImage、deb、rpm

## 1. 环境矩阵

| 编号 | 平台 | 版本 | 硬件 | 是否阻塞发布 |
| --- | --- | --- | --- | --- |
| E1 | macOS | 14 / 15 | Apple Silicon（M 系列） | 是 |
| E2 | macOS | 14 / 15 | Intel | 否（构建产物为 arm64） |
| E3 | Windows | 11 23H2+ | x64 | 否（RC 阶段待验证） |
| E4 | Ubuntu | 24.04 | x64 | 否（RC 阶段待验证） |
| E5 | Fedora | 41 | x64 | 否（rpm 抽样） |

## 2. 用例

### 安装与启动

| ID | 用例 | 步骤 | 期望 |
| --- | --- | --- | --- |
| INST-01 | macOS 安装 | 打开 DMG，把 LingXi Launcher 拖入 Applications，首次启动 | 出现 Gatekeeper 提示时可按 INSTALLATION.md 放行，主窗口正常渲染，无白屏 |
| INST-02 | Windows 安装 | 运行 `setup.exe` 或 MSI | SmartScreen 提示可跳过，安装完成并创建快捷方式 |
| INST-03 | Linux 运行 | `chmod +x` 后运行 AppImage；或安装 deb/rpm | 主窗口正常渲染 |
| INST-04 | 冷启动 | 从点击图标到主界面可交互 | 记录耗时（见 PERF-01），无崩溃 |
| INST-05 | 二次启动 | 关闭后再次启动 | 设置、账户、实例全部保留 |

### 账户

| ID | 用例 | 步骤 | 期望 |
| --- | --- | --- | --- |
| AUTH-01 | 正版登录 | 账户页点击 Microsoft 登录，浏览器完成授权后回到启动器 | 显示玩家名与皮肤，钥匙串写入 refresh token |
| AUTH-02 | 重启保持登录 | 退出并重启启动器 | 无需重新授权即可启动游戏 |

| AUTH-04 | 离线账户 | 创建本地账户并启动 | 以离线用户名进入游戏 |

## 3. 通过标准

1. E1 上 INST/AUTH/VER/WORLD/DATA/DIAG 全部通过，PERF-01 有数据。
2. 三平台安装包均可下载、可安装、可启动到主界面。
3. 诊断信息中不出现 Access/Refresh Token、Cookie、密码。
4. 崩溃或失败用例都记录到 KNOWN-ISSUES.md，并注明是否阻塞。

## 4. 记录方式

- 每个用例记录：平台、结果（通过/失败/未测）、耗时、日志片段。
- 失败用例附诊断信息（脱敏后）与复现步骤，提交到 GitHub Issues。
